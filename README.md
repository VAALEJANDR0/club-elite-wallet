# Clubes de lealtad – imágenes de Google Wallet

Imágenes públicas de las tarjetas de lealtad. Google Wallet las descarga desde aquí.

| Carpeta | Club |
|---|---|
| `elite/` | Club Elite (Elite Brands) |
| `flert/` | CLUB FLERT (FLERT Salón & Spa) |
| `probelleza/` | CLUB PROBELLEZA |
| `anfora/` | CLUB NICHE DU PARFUM (ANFORA) |

Cada club tiene `logo.png` (660×660) y `sellos-00.png` … `sellos-10.png` (1032×812), generadas con `diseno/generar.js` del módulo wallet.
Cada cambio de diseño va en una carpeta de versión nueva (`v2`, `v3`…) porque Google guarda las imágenes en caché.
La carpeta `v1/` de la raíz es la versión original de Club Elite; la usan tarjetas antiguas ya vencidas.
